Memory Banking Ports (128K+)

All 128K-class machines use port #7FFD for primary paging. Some machines add a second port for extended features. Bit 5 of #7FFD locks paging until reset (except Pentagon 1024 in 1MB mode).

Port #7FFD — Primary Paging (128K / +2 / Pentagon / Scorpion)

Decode: (port & #8002) == 0 on 128K/+2/Pentagon; (port & #C002) == #4000 on +2A/+3/Scorpion (stricter).

BitFunction
0-2RAM bank at #C000 (0-7)
3Screen bank: 0 = bank 5, 1 = bank 7
4ROM bank low bit: 0 = ROM 0 (128K BASIC), 1 = ROM 1 (48K BASIC)
5Paging lock — set to disable further paging until reset
6-7Unused on 128K/+2. Pentagon 1024: bank bits 3-4. Ignored on Scorpion.

Port #1FFD — +2A/+3 Special Paging

Decode: (port & #F002) == #1000. Controls special paging mode, ROM bank high bit, and +3 FDC motor.

BitFunction
0Special paging mode: 1 = all-RAM, 0 = normal
1-2Special config (when bit 0 set): 0 = banks 0,1,2,3; 1 = 4,5,6,7; 2 = 4,5,6,3; 3 = 4,7,6,3
2ROM bank high bit (when bit 0 clear). ROM = (bit2 << 1) | 7FFD bit 4 → ROMs 0-3
3+3 FDC motor: 1 = on

+2A/+3 ROMs: 0 = 128K Editor, 1 = 128K Syntax, 2 = +3DOS, 3 = 48K BASIC.

Port #1FFD — Scorpion ZS 256 Extended Paging

Decode: (port & #F002) == #1000 (same as +2A). 256KB RAM (16 pages), 4 ROM banks.

BitFunction
0RAM page 0 over ROM at #0000-#3FFF
1ROM 2 select: 1 = ROM 2 (Service Monitor). 0 = ROM 0/1 via 7FFD bit 4
4RAM page high bit (+8). Page = (bit4 >> 1) | 7FFD bits 0-2 → pages 0-15

Scorpion ROMs: 0 = 128K BASIC, 1 = 48K BASIC, 2 = Service Monitor, 3 = TR-DOS.

Port #EFF7 — Pentagon 1024 Extended Memory

Decode: (port & #F008) == #E000. Controls 1MB mode and RAM-over-ROM.

BitFunction
20 = 1MB mode (bit 5 of #7FFD becomes bank bit 5). 1 = 128K compat mode
31 = RAM page 0 mapped at #0000-#3FFF instead of ROM

Pentagon 1024: 64 RAM pages. In 1MB mode, page = 7FFD bits 0-2 + bits 6-7 (bank 3-4) + bit 5 (bank 5). Bit 5 of #7FFD does NOT lock paging in 1MB mode.

Contention Pattern

48K: Screen lines use 192 T-states for drawing. Memory contention occurs when CPU accesses 4000-7FFF during screen drawing (lines 64-255, T-states 14-126).

128K/+2: Screen lines use 196 T-states for drawing (228 total per line). Contended banks: 1, 3, 5, 7 (odd).

+2A: Same timing as 128K. Contended banks: 4, 5, 6, 7 (high). In special paging mode, contention applies per-slot based on the mapped bank.

Pattern repeats every 8 T-states: 6, 5, 4, 3, 2, 1, 0, 0 (delay in T-states)

I/O contention: ULA port (xxFE) also causes delays when accessed during screen time.

+2A Differences (vs 128K)

  • 4 ROM banks (64KB) selected via ports 0x7FFD bit 4 + 0x1FFD bit 2
  • Port 0x1FFD: special paging, ROM high bit, disk motor
  • 4 special all-RAM paging modes (port 0x1FFD bit 0 = 1)
  • Different contended banks: 4, 5, 6, 7 (not 1, 3, 5, 7)
  • 48K BASIC ROM in bank 3 (not bank 1)

Pentagon Differences

  • No memory or I/O contention
  • 320 lines per frame (more top border)
  • TR-DOS ROM pages in/out via 3Dxx trigger
  • Beta Disk interface at ports 1F, 3F, 5F, 7F, FF

Scorpion ZS 256 Differences

  • 256KB RAM (16 pages), Pentagon-compatible ULA timing
  • 4 ROM banks: ROM0=128 BASIC, ROM1=48 BASIC, ROM2=Service Monitor, ROM3=TR-DOS
  • Port 0x7FFD: standard 128K paging (RAM 0-7, ROM 0/1, screen, lock)
  • Port 0x1FFD: bit 0 = RAM over ROM, bit 1 = ROM 2 select, bit 4 = RAM page +8
  • ROM selection (3-way): 1FFD.1 set → ROM 2; unset → 7FFD.4 selects ROM 0/1
  • TR-DOS built into ROM bank 3 (no separate trdos.rom needed)
  • No memory or I/O contention (same as Pentagon)
