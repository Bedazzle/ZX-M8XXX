UDI keeps raw track bytes and a clock mark per byte, so the checks that matter are the two the spec gets wrong or leaves open: the file checksum (not a standard CRC-32) and the clock bitmap bit order. The track-decode fixtures are real bytes from a real image, with the CRCs that image stores.
